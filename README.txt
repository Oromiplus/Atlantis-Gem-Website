DEPLOYMENT
1. Extract the ZIP file.
2. In Netlify, open the existing Atlantis-Gem site.
3. Open Deploys and use the manual deploy / deploy folder area.
4. Upload the extracted folder contents (the six HTML files and the assets folder together).
5. Open the published site and test navigation, image loading, WhatsApp and quote form.

IMPORTANT
- This package has been prepared locally; it has NOT been deployed to Netlify automatically.
- Keep the assets folder alongside all HTML files when deploying. The pages reference images inside that folder.
- The gallery is ready to expand: place additional approved flyer images in assets and add gallery cards in index.html.
- The quote form prepares a message for WhatsApp/email; it does not store submissions in a database.
